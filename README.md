## 📖 About
This repository documents my progress and projects from the **KubeCraft** course. 
It serves as a testing ground for implementing modern DevOps practices, container orchestration, and automation workflows.

My goal is to translate theoretical concepts into deploying scalable, resilient applications.

* **Monitoring:** Prometheus & Grafana
